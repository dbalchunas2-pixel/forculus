# Dev Reports

Retrospective engineering reports for Forculus.

**What these are:** closed-session records. Each report documents work that is already complete - what shipped, what was decided, and why. Commit SHAs are cited so every claim is verifiable against git history.

**What these are not:** in-progress build logs. Nothing described in a dev report is hypothetical, in-flight, or aspirational. Forward-looking notes, when they exist, will be labeled separately.

## Format

- One report per work session, dated in UTC.
- Sections: Summary, Work completed, Decisions, Metrics (where applicable), What changed since the last report.
- Every claim of completed work is backed by a commit SHA.

## Backfill disclosure

The reports dated 2026-10-14 through 2026-10-16 were written on 2026-10-16, when this cadence was established. They reconstruct genuinely completed work from the commit history and project records - not from memory - and each one discloses its backfill status at the top. Forward-looking reports will be written as each session closes.
